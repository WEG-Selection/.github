# WEG Selection

Sistema desenvolvido para apoiar o processo de gestão de oportunidades
e indicação de aprendizes do CentroWEG.

## Sobre o projeto

O WEG Selection busca centralizar informações relacionadas às oportunidades,
aprendizes e ao processo de indicação, proporcionando maior organização,
rastreabilidade e apoio à tomada de decisão.

## Como funciona

O sistema permite:

- Cadastro e gerenciamento de oportunidades;
- Consulta de aprendizes e informações acadêmicas;
- Ranking técnico dos aprendizes;
- Registro do histórico de conversas;
- Análise de compatibilidade utilizando Inteligência Artificial;
- Indicação de aprendizes para oportunidades;
- Acompanhamento das entrevistas e resultados;
- Controle do processo de alocação.

> A Inteligência Artificial atua como ferramenta de apoio à decisão.
> A decisão final permanece sob responsabilidade do usuário autorizado.
